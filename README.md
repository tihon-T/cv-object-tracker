# Real-Time Object & Motion Tracker (Computer Vision)

A lightweight Computer Vision tool built with Python and OpenCV that tracks specific objects/colors in real-time via camera feed, calculates bounding boxes, center coordinates, and displays real-time FPS.

## 🚀 Features
* **Real-time Color Segmentation:** Uses HSV color space filtering for robust detection.
* **Contour Analysis & Filtering:** Noise reduction using morphological operations (Erosion/Dilation).
* **Bounding Box & Target Tracking:** Dynamic visual overlays with real-time center coordinates.
* **FPS Counter:** Performance monitoring rendered directly on the video feed.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** OpenCV (`cv2`), NumPy
